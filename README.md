# TetrisGame
An LED matrix that lets you play Tetris


This project is a retro-style desktop Tetris game modeled after something like this:
<img width="447" height="447" alt="image" src="https://github.com/user-attachments/assets/e9b16288-7ba6-4e57-9ef7-8327f383b03c" />

This is the final product minus the components:
<img width="572" height="658" alt="Screenshot 2026-11-01 144655" src="https://github.com/user-attachments/assets/91bbff8b-0752-42ac-b6c1-9567e87f7279" />

Components:
- MAX7129 - an LED matrix to show the pieces and display the game
- Elegoo R3 - microcontroller to make the decisions
- KY-023 - a joystick module to move around in the game
- 3 buttons - Start/Pause, Stop, and Store
